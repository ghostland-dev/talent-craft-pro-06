# Talent Craft (v2)

Recruitment platform with job listings and candidate profiles.

## Features

- Job listings and details
- Candidate profile and dashboard
- Recruiter dashboard

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router

## Getting Started

```bash
git clone https://github.com/ghostland-dev/talent-craft-v2.git
cd talent-craft-v2
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
